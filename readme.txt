A trilingual (Persian / English / Chinese) corporate theme for mining, oil & gas and natural stone companies, with 15 dedicated Elementor widgets, Elementor header & footer support and a full theme options panel.

== Description ==

Abidar Group is a production-ready corporate theme built for industrial companies in mining, oil & gas and natural stone.

**Languages** — Persian, English and Chinese ship with the theme. The built-in engine handles direction (RTL/LTR), font switching, cookie persistence, browser detection, hreflang and a 166-string trilingual copy editor in the dashboard. No translation plugin required; WPML and Polylang are detected and respected when present.

**Elementor** — 15 dedicated widgets (hero, services, about, counters, projects, process, team, testimonials, CTA, contact, marquee, posts, accordion, language switcher, page title). Every widget exposes full style controls and reads the theme palette. Header and footer can be replaced with Elementor Pro Theme Builder templates.

**Theme options** — Branding, colours (injected as CSS variables), typography, header layouts (classic / split / centered, sticky, transparent), footer, contact details, blog settings, language editor, custom CSS, plus a one-click demo importer that builds 7 pages, menus, projects, services, team and posts.

**Block editor** — every section is also available as a server-rendered Gutenberg block.

== Installation ==

1. Upload the theme folder to `/wp-content/themes/` or install the ZIP via Appearance → Themes → Add New.
2. Activate the theme.
3. Go to **Abidar → Demo content** and click "Install demo content".
4. Customise under **Abidar → Theme options**.

== Frequently Asked Questions ==

= Do I need Elementor? =
No. The theme renders a complete site on its own. Elementor unlocks the 15 dedicated widgets and the Theme Builder header/footer.

= Do I need a translation plugin? =
No. The theme's own trilingual engine covers the interface copy. For translating page/post content itself, WPML or Polylang work out of the box.

= Are the fonts loaded from Google? =
No. Vazirmatn and Sora are self-hosted (SIL OFL 1.1).
