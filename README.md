# قالب وردپرس گروه صنعتی عبی‌دار — Abidar Group

قالب شرکتی سه‌زبانه (فارسی / انگلیسی / چینی) برای شرکت‌های **معدن، نفت و گاز و سنگ طبیعی** — با ۱۸ المان اختصاصی المنتور (شامل ویجت‌های هدر و فوتر برای المنتور رایگان)، پنل تنظیمات کامل در پیشخوان و دموی یک‌کلیکی.

---

## ۱. پیش‌نمایش زنده

بدون نیاز به وردپرس، ظاهر و حس قالب را ببینید:

```bash
# از ریشه‌ی همین مخزن
python3 -m http.server 8099 --bind 0.0.0.0
# سپس:
#   پیش‌نمایش سایت  → http://localhost:8099/preview/
#   راهنمای تصویری  → http://localhost:8099/preview/docs.html
```

پیش‌نمایش از **همان CSS قالب** استفاده می‌کند، پس آنچه می‌بینید همان چیزی است که وردپرس رندر می‌کند.

| کلید | کار |
|---|---|
| `FA` / `EN` / `ZH` در نوار بالا | تغییر زبان کل سایت (متن، جهت RTL/LTR، فونت) |
| `E` یا دکمهٔ «المان‌های المنتور» | نمایش پنل ۱۸ ویجت به‌همراه **تمام کنترل‌هایشان** |
| منوی اصلی | جابه‌جایی بین صفحات دمو: خانه، درباره، خدمات، پروژه‌ها، تیم، اخبار، تماس |
| «راهنمای قالب» | صفحه مستندات سه‌زبانه (`preview/docs.html`) |

> مستندات کامل نصب و توسعه در `preview/docs.html` و همچنین همین فایل موجود است.

---

## ۲. نصب قالب

1. کل مخزن را در `wp-content/themes/abidar/` کپی کنید (یا فایل ZIP بسازید).
2. پیشخوان → **نمایش → پوسته‌ها** → فعال‌سازی «Abidar Group».
3. پیشخوان → **Abidar → Demo content** → «Install demo content».
   - ۷ صفحه، منوها، ۶ پروژه، ۴ خدمت، ۴ عضو تیم، ۳ نظر، ۳ مطلب، تصاویر و تنظیمات برند ساخته می‌شود.
4. **Abidar → Theme options** → رنگ‌ها، فونت، هدر، فوتر، اطلاعات تماس و ویرایشگر سه‌زبانهٔ متن‌ها.

**نیازمندی‌ها:** وردپرس ۶.۰+، PHP ۷.۴+، المنتور (رایگان) برای ویجت‌ها و المنتور پرو برای Theme Builder.

## ۳. سه‌زبانه بودن — چطور کار می‌کند؟

موتور زبان داخل خود قالب است و **بدون افزونهٔ ترجمه** کار می‌کند:

- سوییچر زبان در هدر، فوتر و به‌صورت ویجت المنتور.
- زبان با پارامتر `?lang=fa|en|zh` عوض می‌شود، در کوکی ذخیره می‌شود و در بازدید بعدی یادش می‌ماند.
- زبان مرورگر بازدیدکننده تشخیص داده می‌شود.
- `dir` و `lang` سند، `hreflang` برای سئو، و کلاس‌های `ab-locale-*` روی `<body>` خودکار ست می‌شوند.
- محتوای صفحات (پست/برگه) با WPML یا Polylang اگر نصب باشند؛ در غیر این صورت با ویرایشگر سه‌زبانه در پنل تنظیمات.

### ویرایش متن‌ها
**Abidar → Theme options → Languages** — یک جدول سه‌ستونه (فارسی / English / 中文) با ۲۶۶ رشته: هیرو، خدمات، درباره، پروژه‌ها، مراحل کار، تیم، CTA، فرم تماس، فوتر، بلاگ و پرسش‌های متداول. جستجو و گروه‌بندی دارد و فیلد خالی به ترجمهٔ پیش‌فرض برمی‌گردد.

### استفاده در کد
```php
abidar_copy( 'hero_title' );          // متن زبانِ فعال
Abidar_Strings::get( 'nav_about', 'zh' ); // ترجمهٔ چینی به‌صورت مستقیم
Abidar_Multilingual::instance()->switcher( [ 'style' => 'dropdown' ] );
```

## ۴. المان‌های اختصاصی المنتور (۱۸ عدد)

همه زیر دستهٔ **Abidar** در پنل المنتور. هر ویجت از پالت قالب ارث می‌برد و تب Style کامل دارد: به‌طور میانگین **۱۶ کنترل استایل** در هر ویجت (بین ۱۱ تا ۲۴) و در مجموع **۲۴۳ کنترل** و **۴۹ گروه تایپوگرافی**، همه ریسپانسیو.

هر ویجت سه لایهٔ استایل دارد:

1. **بخش (Section)** — پس‌زمینه (رنگ/گرادیان/تصویر)، padding، margin، border، border-radius و box-shadow.
2. **عنوان بخش (Section heading)** — تایپوگرافی، رنگ عنوان، رنگ و ترازبندی eyebrow.
3. **اجزای ویجت** — برای هر عنصر متنی (کارت، نام، سمت، عدد، برچسب، پرسش/پاسخ، نقل‌قول، به‌روزرسانی…) یک گروه تایپوگرافی و رنگ جداگانه، به‌علاوهٔ رنگ آیکون، پس‌زمینه/گردی کارت و سایه.

| ویجت | شناسه | نکته |
|---|---|---|
| هیرو | `ab-hero` | تصویر پس‌زمینه، Ken Burns، دو دکمه، نوار آمار، نشانگر اسکرول |
| شبکه خدمات | `ab-services` | کارت آیکونی یا تصویری، لیست ویژگی، لینک، ۱–۴ ستون |
| درباره ما | `ab-about` | تصویر + متن، چک‌لیست، بج تجربه، امضای مدیرعامل |
| شمارنده | `ab-counters` | انیمیشن ورود به دید، پسوند، اعشار، آیکون |
| پروژه‌ها | `ab-projects` | از CPT یا دمو، فیلتر دسته، کارت شاخص، هاور |
| مراحل کار | `ab-process` | تایم‌لاین ۴ مرحله‌ای، شماره یا آیکون |
| تیم ما | `ab-team` | از CPT یا دمو، نسبت تصویر، شبکه‌های اجتماعی |
| نظرات | `ab-testimonials` | اسلایدر/گرید، ستاره، آواتار |
| دعوت به اقدام | `ab-cta` | باند تیره با تصویر و گرادیان، شمارهٔ تماس |
| تماس | `ab-contact` | کارت‌های تماس + فرم AJAX با honeypot |
| نوار لوگو | `ab-marquee` | حرکت بی‌نهایت، توقف با هاور، سرعت |
| آخرین مطالب | `ab-posts` | فیلتر دسته، کارت مجله‌ای |
| آکاردئون | `ab-accordion` | تک‌بازشو، انیمیشن ارتفاع، سازگار با سئو |
| سوییچر زبان | `ab-lang-switcher` | اینلاین یا دراپ‌داون، فلگ |
| عنوان صفحه | `ab-page-title` | هیرو داخلی + بردکرامب |

### هدر و فوتر با المنتور
`Templates → Theme Builder → Header / Footer` را بسازید؛ قالب خودکار جای هدر/فوتر پیش‌فرض را می‌دهد (`elementor_theme_do_location`). همین برای `Single` و `Archive` هم فعال است.

### رنگ‌های گلوبال
پالت قالب (Primary، Accent، Ink، Sand) یک‌بار در Elementor Global Colors ثبت می‌شود تا در همهٔ ویجت‌ها به‌عنوان سواچ قابل استفاده باشد.

## ۷. توسعه

### افزودن رشتهٔ ترجمه
```php
// inc/strings.php
'new_key' => array( 'fa' => '…', 'en' => '…', 'zh' => '…' ),
```
سپس `abidar_copy( 'new_key' )` در هر جا.

### افزودن ویجت المنتور
1. فایل `inc/elementor/widgets/my-widget.php` با `class Abidar_Widget_My extends Abidar_Widget_Base`.
2. افزودن `'my-widget'` به آرایهٔ `$widgets` در `inc/elementor/init.php`.

کلاس پایه `Abidar_Widget_Base` این‌ها را می‌دهد: دستهٔ Abidar، enqueue استایل‌ها، `copy_field()` برای پیش‌فرض‌های سه‌زبانه، `add_heading_controls()` و `add_section_style_controls()`.

### بیلد فایل ترجمه
```bash
wp i18n make-pot . languages/abidar.pot
msgfmt languages/fa_IR.po -o languages/fa_IR.mo
```

## ۸. دسترس‌پذیری و کارایی

- ناوبری کامل با کیبورد، `skip link`، `aria-expanded` روی همهٔ تعاملی‌ها، فوکوس واضح.
- احترام به `prefers-reduced-motion` (انیمیشن‌ها خاموش می‌شوند).
- فونت‌ها self-hosted (Vazirmatn + Sora، لایسنس SIL OFL) — بدون درخواست به گوگل.
- CSS و JS بدون وابستگی خارجی؛ JS ~۷ کیلوبایت.
- تصاویر `loading="lazy"` + `decoding="async"`، تصویر هیرو `fetchpriority="high"`.
- `hreflang`، Schema.org Organization، تگ‌های معنایی.
