۱ · نصب و راه‌اندازی

  1. کپی قالب پوشه قالب را در wp-content/themes/abidar قرار دهید یا فایل ZIP را از نمایش ← پوسته‌ها ← افزودن نصب کنید.
  2. فعال‌سازی پیشخوان ← نمایش ← پوسته‌ها ← «Abidar Group» را فعال کنید.
  3. محتوای نمونه به Abidar ← محتوای نمونه بروید و «نصب محتوای نمونه» را بزنید: ۷ صفحه، منوها، ۶ پروژه، ۴ خدمت، ۴ عضو تیم، ۳ نظر و ۳ مطلب ساخته می‌شود.
  4. شخصی‌سازی در Abidar ← تنظیمات قالب رنگ‌ها، فونت، هدر، فوتر و اطلاعات تماس را تنظیم کنید.

نیازمندی‌ها: وردپرس ۶.۰+، PHP ۷.۴+ و المنتور (نسخه رایگان برای ویجت‌ها، نسخه پرو برای ساخت هدر و فوتر).

۲ · موتور سه‌زبانه

موتور زبان داخل قالب است و به افزونه ترجمه نیاز ندارد. زبان با پارامتر lang در نشانی عوض می‌شود، در کوکی ذخیره می‌شود، از زبان مرورگر بازدیدکننده حدس زده می‌شود و dir/lang سند به‌همراه hreflang خودکار تنظیم می‌گردد.

راست‌به‌چپ، فونت وزیرمتن، اعداد فارسی.

🇬🇧

🇨🇳

چپ‌به‌راست، فونت CJK سیستمی، متن‌های کامل ترجمه‌شده.

ویرایش متن‌ها

در Abidar ← تنظیمات قالب ← زبان‌ها یک جدول سه‌ستونه با ۲۶۶ رشته وجود دارد: هیرو، خدمات، درباره، پروژه‌ها، مراحل کار، تیم، CTA، فرم تماس، فوتر، بلاگ و پرسش‌های متداول. هر فیلد خالی به ترجمه پیش‌فرض برمی‌گردد.

// متن زبان فعال
abidar_copy( 'hero_title' );

// ترجمه چینی، مستقل از زبان فعال
Abidar_Strings::get( 'nav_about', 'zh' );

// سوییچر زبان با استایل دلخواه
Abidar_Multilingual::instance()->switcher( [ 'style' => 'dropdown' ] );

هدر و فوتر با المنتور

در قالب‌ها ← Theme Builder یک Header و یک Footer بسازید؛ قالب به‌طور خودکار جای هدر و فوتر پیش‌فرض را می‌دهد. همین رفتار برای Single و Archive هم فعال است.

رنگ‌های گلوبال

پالت قالب (Primary، Accent، Ink، Sand) یک‌بار در Elementor Global Colors ثبت می‌شود تا در همه ویجت‌ها به‌عنوان سواچ قابل استفاده باشد.

۵ · محتوای نمونه و این پیش‌نمایش

این پیش‌نمایش استاتیک از همان CSS و ساختار HTML قالب استفاده می‌کند؛ بدون نیاز به وردپرس می‌توانید ظاهر، تغییر زبان و کنترل‌های ویجت‌ها را ببینید. برای دیدن نسخه واقعی، قالب را نصب و محتوای نمونه را اجرا کنید.

  • ✓قالب کامل و نصب‌شدنی با فایل‌های PHP، CSS و JS
  • ✓۱۶۶ رشته ترجمه در سه زبان، قابل ویرایش از پیشخوان
  • ✓۱۵ ویجت المنتور با تب Style کامل
  • ✓۶ قالب صفحه: خانه، درباره، خدمات، پروژه‌ها، تیم، تماس
  • ✓بلاک‌های گوتنبرگ برای هر سکشن صفحه
  • ✓فایل ترجمه POT و ترجمه فارسی PO/MO
